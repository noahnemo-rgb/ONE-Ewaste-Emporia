## Overview

**ONE E-Waste Emporia** operates a nationwide/regional mail-in e-waste, computer refurbishment, and data recovery ministry. We combine environmental care with human flourishing by transforming obsolete and non-functional electronics into tools for community uplift.

### The Three Operational Tracks

1. **The Data Sanctuary (Data Recovery & Privacy):**
   - Non-invasive logical and hardware write-blocked extraction of family photos, documents, and historical records.
   - NIST SP 800-88 Rev. 1 compliant cryptographic drive wiping with verifiable destruction certificates.
2. **Refurbishment & Digital Bridges (Upcycling):**
   - Comprehensive diagnostic testing, ultrasonic cleaning, and RAM/SSD hardware upgrades.
   - Clean installations of lightweight, privacy-preserving open-source operating systems.
   - Direct distribution to low-income students, seniors, and non-profit partners.
3. **Sacred Earth Stewardship (Responsible Recycling):**
   - Manual teardown of non-viable devices into clean material streams (aluminum, copper, PCB gold traces, plastic casings).
   - Zero-landfill, zero-toxic-export partnership with certified R2v3 downstream refiners.

## Getting Started

### Local Preview

Simply clone the repository and open `index.html` in your web browser:

```bash
git clone https://github.com/noahnemo-rgb/ONE-Ewaste-Emporia.git
cd ONE-Ewaste-Emporia
open index.html # On macOS, or double click index.html
```

### Deploying to GitHub Pages

1. In your GitHub repository, navigate to **Settings** > **Pages**.
2. Under **Build and deployment**, select `Deploy from a branch`.
3. Choose the `main` branch and `/ (root)` folder, then click **Save**.
4. Your site will be live at `https://noahnemo-rgb.github.io/ONE-Ewaste-Emporia/`.
